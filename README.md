# vivory-research-reproductions

Public reproduction notebooks for [Vivory Research Reproducibility Hub](https://research.vivory.app/reproductions).

Each reproduction lives at `reproductions/{id}/notebook.ipynb`. Notebooks are:
1. Auto-generated by the Vivory backend from arXiv paper metadata + repo + Papers with Code.
2. Committed here via the GitHub Contents API.
3. Run on free-tier hardware (GitHub Actions CPU, or Kaggle T4 GPU for heavier workloads).
4. Metrics captured as `metrics.json` artifacts → ingested back into research.vivory.app.

## Run a reproduction yourself

Every notebook has a one-click Colab button. Click, run, observe — you can
reproduce our reproductions. That's the whole point.

## Contribute

Found a bug in a reproduction? Open an issue. Have a better notebook for
a paper? Open a PR — we'll rerun it and update the metrics.

## Infrastructure

- Ingestion / generation / orchestration: [github.com/jayjodev/vivory](https://github.com/jayjodev/vivory)
- Frontend: [research.vivory.app/reproductions](https://research.vivory.app/reproductions)
- Runners: Kaggle Notebooks API (GPU) · GitHub Actions (CPU)
